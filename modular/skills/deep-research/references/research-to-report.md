# From a research question to a report

Start with the reader's decision or question, including scope, date and what would change the answer. Allow an orientation search to discover terminology. For the deciding unknown, ask where an observable trace would exist. Search for that trace using entity names, versions, units or identifiers found in sources.

### Search and change course

An official manual establishes intended API behavior. A test on the pinned version can establish observed behavior. A study can support an effect only within its population, comparator and design. A practitioner account can reveal a failure worth testing. Choose accordingly. Open the relevant text, figure, code or release note. Follow secondary coverage to the original when the distinction changes confidence. If the leading account and its strongest rival predict different outcomes, search for the distinguishing observation. A failed search bounds that route; try a different source ecosystem, language or primary identifier when it matters.

For pivotal claims retain a short working note: claim; exact locator and scope; what it supports; lineage; counterevidence or remaining gap. Use the existing task state. For routine facts a direct source suffices. Group syndications and reports using the same dataset. Keep inaccessible sources labeled. Before compression preserve the exact locator of any result that reverses or narrows a conclusion. Reopen it when the summary cannot support the claim.

### Update the answer

When new evidence arrives, identify which premise changes. Recompute affected ranges, confidence or recommendations. Keep stable conclusions intact. Distinguish missing evidence from a negative result. Do not manufacture symmetry between a documented result and an unsupported alternative. If successive searches repeat an origin, try one genuinely discriminating route when available. End when the material decision is stable, or state exactly which unresolved condition can still reverse it.

### Write for use

Select the form by purpose: a direct answer for a bounded fact, a comparison table for matched dimensions, a narrative for a timeline, or a sourced report for a material investigation. Put the answer and its important condition early. Attach sources to the particular claims they support. Expose disagreements in terms of versions, regions, denominators, methods or time periods. Keep extrapolation visible. Preserve unknowns in the final recommendation and give the reader the implication. Inspect any decisive number, quote, attribution or clickable evidence locator before delivery.

For evaluation, use a fixed corpus to diagnose retrieval vs interpretation and a dated live-web run to assess current performance. When a decisive source is supplied directly after a failed search, a correct second answer is a clue about the bottleneck. Benchmark answers and graders must remain outside the working corpus. See [BrowseComp-Plus](https://texttron.github.io/BrowseComp-Plus/) and [ALCE](https://aclanthology.org/2023.emnlp-main.398/) for controlled retrieval and citation evaluation.
