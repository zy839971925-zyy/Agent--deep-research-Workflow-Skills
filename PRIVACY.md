# Privacy

Reasoning Workflow is a local/open-source workflow package. This repository does not operate a hosted backend and does not independently collect, store, or sell user data.

When the workflow is used inside ChatGPT, Codex, Claude Code, another agent host, or with external tools/connectors, data handling is governed by that host and by the services the user chooses to invoke. Reasoning Workflow itself instructs agents to preserve source boundaries, minimize unnecessary disclosure, distinguish access from authorization, and avoid treating private evidence as permission to publish it.

Do not place secrets, credentials, sensitive personal data, or private work artifacts in public issues, commits, or other publicly shared materials.
