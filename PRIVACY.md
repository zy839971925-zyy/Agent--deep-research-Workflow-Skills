# Privacy

Reasoning Workflow is a skill-only workflow package. This repository does not operate a hosted backend and does not independently collect, store, or sell user data.

When the workflow is used inside ChatGPT, Codex, another agent harness, or with external tools/connectors, data handling is governed by that host and by the tools or services the user chooses to invoke. The workflow itself instructs agents to minimize disclosure of private evidence, preserve source boundaries, and avoid treating access as authorization to publish.

Do not place secrets, credentials, or sensitive personal data in public issues, commits, test fixtures, or shared run artifacts.
