# Reasoning Workflow 3.1.0 发布说明

本次功能更新让调研路由根据场景自动判断，并明确工作流深度的默认选择，同时保留宿主已选模型。

- 根据请求推断现实/经验研究、开发前工程/架构研究或两者结合的证据路径；不要求用户先给任务贴标签。
- 默认使用宿主当前选择的模型；按任务需求自动选择适当的 Light–Ultra 工作流深度。用户明确指定深度时以其要求为准。Ultra 改变的是工作流投入，不代表切换模型、增加权限/自主性或固定来源/代理配额。
- 在 Modular Deep Research Skill 中同步路由语义，并增加一项协议场景与跨任务案例。
- 确定性检查只验证规则文本、夹具及结构，不证明真实模型行为或质量提升。
