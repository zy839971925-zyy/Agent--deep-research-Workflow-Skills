# Release 3.1.0

This feature update makes research routing scenario-led and clarifies automatic workflow depth while preserving the host-selected model.

- Infer real-world/empirical, pre-build engineering/architecture, or linked hybrid evidence paths from the request; users need not label the lane.
- Use the host-selected model by default. Infer proportionate Light-to-Ultra workflow depth from task needs; explicit user depth requests take precedence. Ultra changes workflow effort, not model identity, permissions, autonomy, or quotas.
- Mirror the routing contract in the Modular Deep Research Skill and add a protocol scenario and cross-task case.
- Deterministic checks verify contract text and fixtures only; no real-model behavior or quality gain is claimed.
