# Reasoning Workflow 2.2.0：研究方法与宿主适配

状态：本地候选版本；尚未推送、发布或创建 PR。基线为 2.1.1。

## 这次解决什么

上一版通用框架已经覆盖问题重构、答案依赖、来源谱系、反例/边界和停止判断。此次不再堆一层普遍“多想一步”的流程，而是补能直接改变检索、比较与续接的可执行方法，并按实际 host 分开说明能力。

### Deep Research 方法

- **Research frontier**：对会改变结论的分支，记录尚未解决的 pivotal claim、竞争解释、区分性观察和下一条最有价值的证据路线；读完之后更新状态。它是紧凑工作状态，不是用户输出清单或搜索配额。
- **初稿后的缺口搜索**：仅对决定性主张标注支持、部分支持、冲突、未核验或覆盖缺口，选择最大的材料性缺口，必要时搜一条独立/反向路线；初稿是检索指引，不是证据，也不要求逐句审计。
- **缺口驱动的引文追踪**：当关键缺口可能由相关文献解决时，向后找原始方法/结果，向前找复现、批评、修正或撤稿；识别共享数据、报告源和评估流水线。没有固定来源数量，重复回到同一来源家族时停止或转向。
- **跨研究比较卡**：按问题触发，抽取版本、样本/任务、设计、对照、预算与工具、指标定义、分母、效应和不确定性、偏差、资金关系、来源谱系。条件不相容时分层或并列呈现，不强行排名或合并效应。

### GPT-6+、前沿模型与宿主

将活动模型适配改成“先看真实模型 + harness 能力，再选方法”：强推理用于问题建模、证据冲突裁决和综合；窄任务可交给更轻量模型/处理，但只有当前 host 真实支持时才并行。更大的上下文不等于已读完材料；长任务应保存可续接的证据包，而不是依赖隐藏推理或早期工具输出。没有代理时，Ultra 按单线逐条推进，不伪称并行、不降低研究深度。

同一研究核心现在有 Codex、Claude Code、ChatGPT/Claude/Grok 聊天端的宿主说明。技能目录、项目指令、搜索、Research、MCP、代理、连接器和视觉 UI 的可用性各不相同，取决于客户端/账号/工作区配置。ChatGPT Intelligent UI 采用有条件的主动策略：当交互图表、比较或示意图明显改善对数据/关系/取舍的检查且当前界面支持时优先使用；否则给清晰的文本/表格。Skill 本身不能安装 App 或强制 UI。

官方产品文档证明的是接口或功能边界，不是 GPT-6、Claude 5.5/5.1 的研究质量提升；本版没有真实模型成对行为评测，也不声称效果已经量化改善。

## 仓库与发布维护

- 根 README 和包 README 现在按宿主解释版本选择、安装和降级方式。上一版 2.1.1 的集成记录、历史入口和校验数据保留，不覆盖为“当前事实”。
- Modular Deep Research 单独安装时曾缺少导航引用，现增加自己的 information-target 导航文件和比较方法，并把综合审计材料放回其实际所属 Family。
- `run_all.py` 默认仅运行测试、不重写已提交的机器路径回执；只有显式 `--output-dir` 才写新摘要。新增确定性 ZIP 构建器、归档成员与源码精确比较，并在静态检查中核对发布版与入口。
- 2.1.1 ZIP 原样保留为历史版本；2.2.0 另建新 ZIP 和校验和。

## 实际验证边界

`TEST_REPORT.md` 记录本次实际运行结果。结构/Schema/链接/源码归档一致性与合成测试，只能证明这些机械契约通过；它们不能证明模型会按指南执行，也不能证明研究结论质量提升。
