# Changelog

Reasoning Workflow no longer uses public numbered release branding. The Git history is the chronological source for changes.

The current architecture includes:

- Universal Reasoning Spine with Question / Reasoning and Action / Project lanes
- Task Admission / Depth Gate and versioned Task Profile for runtime consistency
- deterministic Skill Family and reference routing
- progressive context disclosure
- model-driven Deep Research
- typed semantic lifecycle and effective-state propagation
- Plan / Schedule / Worker / Checkpoint / Recovery controls
- depth-gated dual-layer verification
- trace-based Skill adherence evaluation
- CAPA-style failure analysis and eval-gated learning
- portable and modular distributions built from one source of truth
