# Architecture recommendation — synthetic draft v2

## Local export/import
A local export/import path preserves the offline-first baseline and user-controlled key custody, with explicit recovery steps and a versioned import preview.

## Provider-backed restore
A hosted provider is the recommended default because it guarantees users can recover their keys from the server.
