# Deep Research Evaluation Harness

This directory defines evaluation dimensions and task adapters. It intentionally does not copy benchmark corpora.

External benchmark inspirations/adapters:
- FutureSearch Deep Research Bench (arXiv:2506.06287): multi-step web tasks, frozen-web reproducibility, trace hallucination/tool-use/forgetting checks.
- DeepResearch Bench (arXiv:2506.11763): expert research tasks, report quality and citation accuracy/effective citations.
- DeepResearch Bench II (arXiv:2601.08536): fine-grained atomic rubrics across information recall, analysis and presentation.
- ReportBench (arXiv:2508.15804): citation relevance/quality, statement faithfulness and factual veracity.

Do not aggregate all dimensions into one universal score. Report them separately.
